# K0

K0 is a TypeScript and Rust workspace that includes a Tauri desktop product and Convex-backed services.

> **Project status: active development.** APIs, behavior, deployment requirements, and security controls may change without notice. Review the source and release materials before depending on K0 in a production or regulated environment.

## Security

K0 includes security-oriented CI and release controls, but no software is safe by default in every deployment. Do not commit credentials, signing keys, customer data, or production configuration. Configure environment protections and secrets independently for each deployment.

Report vulnerabilities privately as described in the [security policy](./.github/SECURITY.md). Do not publish exploitable details in an issue.
