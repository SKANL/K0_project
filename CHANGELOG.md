# Changelog

All notable user-facing changes to K0 are documented in this file.

K0 follows [Semantic Versioning](https://semver.org/) for stable releases. Versions are published as Git tags in the form `vMAJOR.MINOR.PATCH`.

## Release notes

Each stable GitHub release is generated from an annotated `vMAJOR.MINOR.PATCH` tag. Canary and beta builds are pre-releases and do not receive a changelog version heading until promoted to stable.

See [release engineering](./docs/release-engineering.md) for the maintainer procedure.
