# Support

## Security issues

Do not use public issues for suspected vulnerabilities, exposed credentials, or exploitable behavior. Follow the private reporting process in [SECURITY.md](./.github/SECURITY.md).

## Bugs and reproducible problems

Use the repository's bug-report template. Include the K0 version or commit, operating system, steps to reproduce, expected and actual behavior, and relevant logs with secrets removed.

## Feature and usage questions

Search existing issues and documentation before opening a new issue. Keep requests focused on the problem and operational context rather than a preselected implementation.
